# TaskFlow

TaskFlow — статическое веб-приложение для отслеживания и выполнения задач. Приложение работает в браузере без серверной части и хранит задачи в `localStorage`.

## Как посмотреть приложение

1. Откройте терминал в папке проекта.
2. Запустите локальный сервер:

   ```bash
   npm start
   ```

3. Откройте в браузере адрес http://localhost:4173.
4. Чтобы остановить сервер, вернитесь в терминал и нажмите `Ctrl+C`.

> Важно: открывать `index.html` двойным кликом не рекомендуется, потому что браузер может заблокировать JavaScript-модули для локальных файлов. Используйте локальный сервер из команды выше.

## Возможности

- создание задач с названием, описанием, приоритетом и сроком;
- переключение задач между статусами «в работе» и «выполнено»;
- удаление задач;
- поиск по названию и описанию;
- фильтры по статусу: все, в работе, выполненные и просроченные;
- дашборд с количеством задач, активных задач, выполненных задач, просрочек и процентом выполнения.

## Команды

```bash
npm start
npm test

```
